---
title: weebo-authentik-operator
description: A Kubernetes operator that manages Authentik resources as CRDs.
---

`weebo-authentik-operator` lets you manage Authentik groups, users,
applications, and access policies as native Kubernetes custom
resources, with a namespace-scoped allow-list enforced via an admission
webhook.

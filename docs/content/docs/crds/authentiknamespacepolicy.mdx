- **Scope:** Cluster
- **Short names:** none
- **Guide:** [The allow-list](/docs/guides/allow-list)

Namespace allow-list enforced by the admission webhook (and
double-checked by reconcilers). Cluster-scoped. Default-deny: a
`(namespace, kind)` pair is only allowed if some rule across every
`AuthentikNamespacePolicy` explicitly allows it — see
`domain::allow_list::evaluate`, which this CRD's rules map directly
onto.

## Example

```yaml
apiVersion: authentik.weebo.io/v1alpha1
kind: AuthentikNamespacePolicy
metadata:
  name: my-namespacepolicy
spec:
  rules:
    - namespaces:
        - team-a
      allowedKinds:
        - AuthentikApplication
        - AuthentikAccessPolicy
      effect: Allow
```

| --- | --- | --- | --- | --- |
| `allowedKinds` | `string[]` | yes |  | Values: `"AuthentikApplication"`, `"AuthentikAccessPolicy"` |
| `effect` | `string` | yes |  | Values: `"Allow"`, `"Deny"` |
| `namespaces` | `string[]` | yes |  | Exact namespace names, `*`, or a prefix glob such as `team-*`. |

Deliberately minimal — nothing in the Terraform module being replaced
creates a custom outpost, everything attaches to Authentik's embedded
outpost by default. This CRD exists only to cover the case where a
proxy provider's `outpostRef` explicitly names one. Cluster-scoped.

## Spec fields

| Field | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `config` | `object` | no |  | Passthrough to the Authentik API — deliberately not modeled field by field. `x-kubernetes-preserve-unknown-fields` is required here: a bare `serde_json::Value` schema has no `type`, which a real structural-schema apiserver rejects outright ("must not be empty for specified object fields") — caught by the layer-3 envtest integration test, not by `cargo check`. |
| `name` | `string` | yes |  |  |
| `type` | `string` | yes |  |  |
